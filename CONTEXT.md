# CONTEXT — STT-WHISPER-LOCAL

Память проекта: суть, стек, роли, текущий фокус. Обновляет архитектор.

## Суть
Заменить Wispr Flow (падает/зависает) на стабильную бесплатную или дешёвую
голосовую диктовку на Windows. Домен: STT — распознавание речи (голос -> текст).

## Машины и среда
- **Целевая машина проекта: десктоп RTX 4060 (8 ГБ VRAM), 32 ГБ RAM** — на нём
  проект продолжается.
- Первичная установка и тест трека A выполнены на другом десктопе (RTX 3050):
  там при запуске установщика CUDA mismatch (found 6.5 / requires 12), поэтому
  тестировали на CPU.
- Синхронизация между ПК — через GitHub (DEV-NOTES §7).
- Windows 11, Python, PowerShell 7 (`pwsh`). FFmpeg глобально (§8), фикс UTF-8 (§12).
- Диск: рабочий том `G:` (§15.4). Архив `H:` агенту не подключать.

## Два трека
- **A (база): whisper-local** (`drajb/whisper-local`) — офлайн, faster-whisper /
  CTranslate2, хоткей Ctrl+Win (push-to-talk), конфиг
  `%APPDATA%\whisperkey\user_settings.yaml`, лаунчер 0.18.3.
  **Статус: проверен на CPU** (base, int8) на машине RTX 3050 — русская диктовка
  распознаётся и вставляется. Осталось развернуть на целевой RTX 4060 + GPU.
- **B (качество, потом): свой скрипт на Google Gemini 3.5 Transcribe** (Live API) —
  распознавание + встроенная зачистка в один проход. BYOK-ключ AI Studio,
  ~$0.009/мин стриминга (~$3-8/мес при умеренном использовании).

## Роли
Архитектор (чат) / кодер (терминал) / консультант-ревьюер — DEV-NOTES §1, §1.1.

## Текущий фокус
Трек A работает как CPU-базлайн. Дальше: развернуть на машине RTX 4060, включить
GPU (проверить CUDA 12), затем трек B.

## Важно про конфиг
`%APPDATA%\whisperkey\user_settings.yaml` — **пер-машинный**, в репозиторий НЕ входит.
На целевой машине настраивается заново (рекомендации — в AGENTS.md, трек A).

## Открытые вопросы
- CUDA 12 на целевой RTX 4060 — проверить (на RTX 3050 установщик видел CUDA 6.5,
  вероятно старый cudart в PATH перебивает актуальный).
- Модель под русский: на CPU хватает base/small; large-v3 — для GPU на RTX 4060.
