# TASK — активное задание (архитектор -> кодер)

Статус: активно | Дата: 2026-09-06

## Цель
Развернуть трек A (whisper-local) на **целевой машине RTX 4060** и включить GPU.

## Предыстория
На машине RTX 3050 трек A уже проверен на CPU (см. REPORT.md / PROJECT_LOG.md):
диктовка на `base` работает, русский распознаётся.

## Шаги
1. Скачать `whisper-local.exe` (releases/latest), сверить sha256 с `.sha256` рядом.
2. Запустить. При запросе GPU проверить CUDA: нужен CUDA 12 runtime + cuDNN,
   совместимые с CTranslate2 4.7.1. Если снова "found CUDA 6.5" — почистить PATH от
   старого cudart (найти, показать список, только потом править).
3. Включить GPU. В `%APPDATA%\whisperkey\user_settings.yaml`:
   `language: ru`; `model: large-v3` (8 ГБ VRAM хватает).
4. Тест: Блокнот -> зажать Ctrl+Win -> русская фраза -> проверить скорость и качество
   (large-v3 на GPU должен быть быстрым и точнее base).
5. Заполнить REPORT.md — только по фактической проверке запуском (DEV-NOTES §16).
