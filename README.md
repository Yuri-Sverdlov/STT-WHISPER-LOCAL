# STT-WHISPER-LOCAL

Подбор и настройка стабильной голосовой диктовки (речь -> текст, STT) на Windows
взамен Wispr Flow (периодически падает/зависает).

- Суть, стек, треки, текущий фокус — `CONTEXT.md`
- Правила кодера — `AGENTS.md`
- Журнал сессий — `PROJECT_LOG.md`
- Активное задание / отчёт — `tasks/TASK.md`, `tasks/REPORT.md`

Общий канон среды разработки (не дублируется здесь): `G:\AI\DEV-NOTES\DEV-NOTES.md`.
